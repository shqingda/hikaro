# 向光 · 非字母图案探索

用户后续反馈：保留太阳圆点，主体改为非字母图案；功能优先。本目录是可撤回的独立候选，未覆盖 `brand/identity` 或此前 `2026-10` 的 h 形光学修订稿。

[打开静态评审稿](index.html)。本地现有预览服务：`http://127.0.0.1:4173/brand/explorations/2026-10-horizon/`。

主体是一道没有竖直字干的低拱面，下方一条直地平线；太阳偏向右上方，保留原方案的方向感。视觉目标是向上打开的空间与日出，不用字母、屋顶、星芒或多余外框。它仍需与常见日出 / 户外品牌做识别度比较，当前不宣称唯一性。

- `mark.svg`、`mark-on-ink.svg`：双色日出图案，明暗背景各一份。
- `compact.svg`：16 / 24 px 独立简化稿，删除容易糊成重底的地平线，加重弧面；不是机械缩小主图。
- `app-icon.svg`：1024 画布上的深色容器，四周留 100 单位透明余白。
- `index.html`：并列展示主标、反白、16–88 px、应用图标及原字标。无 JavaScript、网络请求、动画或新增字体。

配色原样保留：Beam `#F2B500`、Ink `#12120F`、Paper `#F7F7F6`。字标直接引用原有 `brand/identity/assets/wordmark.svg`，未重绘 Literata 字形；其字体许可仍位于 `brand/identity/fonts/OFL.txt`。

遵循 apple-design 的克制、明确层次和小尺寸可读性原则：先保证轮廓、空间与对比，不添加渐变、光晕、阴影或无目的运动。此轮没有生产替换、原生应用图标验收或商标检索；性能测量期间不启动额外浏览器评审。
