# 手机图片与文件差异阅读

任务消息中的图片可按需逐张打开，提供前后切换、缩放和错误重试；不加载外部 URL，不保存到手机文件或相册。只接收已授权任务的 base64 图片，分段校验 MIME、总长度、游标和数据格式，预览上限为 16 MiB base64（最多 12 MiB 原始数据）。这是明确的单图预览资源限制，不是发布性能门槛；超限给出可见提示，不截断冒充完整图片。

任务页增加文件变更入口，按现有记录分页；显示路径、创建/编辑、记录状态，读取统一 diff。新增可协商的只读 `changes.diff`，电脑复用 TUI 同一 diff 算法生成，手机每次只保留一段，Unicode 边界完整。它反映记录的前后快照，不能声称是当前工作区状态，Shell/插件等未记录修改仍明确不覆盖。手机本轮不提供回退写入。

图片和 diff 使用独立阅读模块绑定当前连接与任务。断线、后台、换任务、撤销和关闭清空内容并使迟到回复失效；重新连接不自动重放读取或恢复敏感内容。旧 host 不支持差异接口时禁用入口并明确提示升级。

验证覆盖格式/游标/容量边界、分段读取、换任务/关闭/撤权的迟到回复、差异分页与记录变化。唯一自动 E2E 使用实际 shared host/SQLite 和设备 view 权限，验证图片、差异、其他任务拒绝及撤权。必要类型检查、CLI 构建和双平台导出后，再在现有原生客户端验收可视输出。Android/真机与完整发布验收单独保留。

`changes.diff` 是通过 `hello.methods` 协商的增量只读 RPC。输入为当前授权 `sessionId`、记录 UUID `id`、UTF-16 `offset`（默认 0）和 `limit`（默认 8192，上限 16000）；返回 `{ entry, data, total, encoding: "utf16", nextOffset }`，末页游标为 null。权限与 `changes.list/detail` 相同；不改变旧接口。手机用既有重叠字符分页规则避免截断代理对，记录身份变化时要求刷新列表。验收结果见[本轮记录](../validation/mobile-inspection.md)。
