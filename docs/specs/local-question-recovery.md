# 普通 TUI 未答问题恢复

普通非 host TUI 的 `ask_user` 复用 host 的问题服务和 SQLite 事务。问题先保存，再展示；记录真实执行会话及审批归属会话。稳定身份 `standalone:tui` 与 host 的 `default`、`local:*`、设备身份隔离，每次进程启动生成新的实例 ID。

启动或切换会话时提示该身份的未答问题，用户通过 `/questions` 打开。恢复答案与原问题作为用户上下文原子保存一次；取消也持久记录。恢复不启动模型、工具、子任务或待发消息，不恢复旧 Promise，不改变 Plan 模式。继续操作必须由用户另发消息。

退出必须先关闭问题服务，再取消运行和销毁界面；界面销毁不等于用户取消。关闭 SQLite 前等待问题与草稿写入。会话切换或退出使迟到的界面结果失效。恢复提交沿用执行租约保护，旧租约未到期或当前会话仍在运行时拒绝提交；当前答案保留供手动重试，不自动重发。

不迁移身份，不恢复过去从未保存的问题。未提交的答案输入草稿仍是后续工作。

验证：真实 SQLite 的普通问答保存、退出保留、显式取消、身份隔离、切换竞态与租约拒绝；现有 host 回归保持通过。真实普通 TUI 经 SIGKILL 后重启，回答后模型请求数不变，用户新发消息才继续，Plan 保持只读。

结果与剩余边界见 [验收记录](../validation/local-question-recovery.md)。
