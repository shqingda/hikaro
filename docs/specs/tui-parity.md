# 普通与附着 TUI 核心流程对齐

本切片覆盖 /changes、/tasks、/plan 与结构化提问，复用普通 TUI 面板，不以 JSON 输出或 RPC 方法存在作为交付。

Host 保管文件快照、执行状态、计划版本和未回答问题。新增方法加入 capabilities；所有修改使用原有持久命令回执，不自动重放。所有请求绑定明确 sessionId，控制请求必须仍选中该会话、具备 control/owner 权限。恢复仅查询，未知结果显示并要求核对。

变更列表分页，前后快照分块传输，核对记录版本后组装完整差异。回退仍由 Runtime 在 host 持锁、比较内容、记录结果。

执行管理复用界面和 typed source：列表摘要，选中后读完整有界输出；修改等待 host 确认。暂停队列以客户端 token 绑定会话，读取续期，超时自动释放；关闭显式释放，断线不重放动作。其他控制端操作导致旧条目失效时显示错误。

Plan 与问题在 host 执行。问题保留到回答/取消/任务终止；断线只关闭本地面板，重新连接可再次读取未答问题，不自动作答。回答竞争仅首个生效。批准当前版本与发起执行共用一个受回执保护的命令，回复丢失后核对结果，禁止自动重发。

定向验证：host 工作流方法及授权/重复命令/分块；普通面板回归；单个真实 host + attached PTY 脚本走通 Plan/回答/确认执行、审阅回退、队列/终端/子任务操作。连接恢复沿用现有回执回归。类型检查与构建，不跑全量或性能基准。
