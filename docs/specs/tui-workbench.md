# Hikaro 终端工作台

2026-10-30 用户批准：保留 Pi 的模型、终端、编辑及互通能力，建立 Hikaro 自己的界面风格。范围为原生、附着 host、外部 Pi 后端和 Pi 内嵌入口；不改变公共协议、数据库、执行循环或各入口的功能范围。

## 视觉与交互契约

- Beam `#F2B500`、Ink `#12120F`，浅色强调文字 `#6B5000`；正文采用终端本身前景和背景。`NO_COLOR` 禁用主题 ANSI。
- 顶部轻量 hikaro / 工作区 / 分支，中央单列消息，面板按需显示在输入区上方，状态栏固定最底部。
- 输入只有一条地平线，末行是操作提示。保留 Pi 编辑、Unicode、粘贴、历史、撤销和自动补全。正文最多六行，低屏缩减；坐标映射随 viewport 调整，补全不改私有字段或依赖源码。
- YOU/HIKARO 标签替代用户整块底色。Markdown 保留流式缓存和分页。工具显示状态、名称、参数中已有的目标；结果原位更新，失败保留原因。`/tools` 展开已加载结果及后续结果；手动工具输出保持可见。
- 正式菜单使用 Hikaro 自有选择状态，一行一个项目，最多八项，选中项以 Beam 底色标记；完整说明可 PgUp/PgDn 查看。保留异步搜索、默认值、删除/重命名的能力约束。审批默认 Deny，保留防误 Enter 与审阅空间不足禁止 Allow。
- 状态栏优先显示真实执行/连接状态和权限，空间足够时展示模型与用量；隐藏用量不隐藏权限。长错误正文可在会话区域滚动阅读，输入旁只占最多两行。
- Pi 内嵌入口共享主题和输入组件，保留 `/back`、断线草稿和原有审批流程；扩展始终使用 Pi 宿主的 TUI 模块。

## 实施与验证

内部 `ViewStatus` 取代拼接状态字符串。工具摘要由既有调用 ID、消息和事件派生，不增加持久状态。显示偏好格式保持不变。

验证覆盖四种尺寸（120×40、80×24、60×18、40×12）、明暗和无颜色、光标与鼠标映射、补全、搜索、审批、历史滚动、状态恢复和 Pi 打包隔离。新样式直接作为默认值，不提供第二套旧主题。
