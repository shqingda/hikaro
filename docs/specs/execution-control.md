# TUI 执行管理

普通 TUI `/tasks` 提供待发消息、后台终端和子 agent 三个入口，运行中也可打开。只有实际界面操作与结果验证通过才标为完成。

待发消息：展示完整文本与附件数量，编辑文本、提前到队首、删除。打开管理器期间暂停待发队列派发，当前任务继续；关闭后恢复。操作针对稳定 ID，已开始的任务不能被误改。此切片队列仍驻内存，跨重启恢复单独待办。

后台终端：展示本会话命令、运行/停止中/退出码；分页阅读最近输出，不消费模型的输出缓冲；发送一行输入前确认，停止前确认；只有收到退出事件才显示退出。保留有限数量的终态用于核对，不管理任意 OS 进程。

子 agent：只显示当前父会话直接委派的任务，任务、状态、最近输出/最终结果；停止前确认。停止请求与最终 cancelled/completed/failed 分开显示。运行时记录有界，重启后的会话历史仍可通过 `/sessions` 查看，本面板不重放任务。

每类都有刷新、返回、空状态、错误提示；进程和子 agent 详情每 250 ms 更新一次，内容未变时不重绘；完整操作目标放不下时禁止确认。面板退出恢复焦点与草稿。附着 TUI 的同等入口继续属于后续 parity 工作，不宣称已实现。

验证：新增 execution-control 定向核心/终端/运行时测试；TUI 交互测试；一个本地 SSE fixture 驱动的真实 CLI PTY 脚本覆盖三类操作与终态。类型检查、构建。遵循 TODO 的定向测试和失败修正限制，不运行全量套件或性能基准。

## 交付

普通 TUI 命令帮助和补全已提供 `/tasks`。退出管理器恢复待发队列；运行期间出现审批时管理器退出，让出审批焦点。后台终态最多保留 32 条，子 agent 终态约保留 100 条；详情保留最近 64,000 字符并提示终端输出截断。终端停止使用现有 PTY 停止信号，忽略信号时保持 stopping；此版本未实现强制停止和进程树核对。

验证结果与已知边界见 [执行管理验收](../validation/execution-control.md)。
