# 未答问题跨 host 崩溃恢复

范围为独立 host 的 `ask_user` 与附着 TUI。问题先持久化再展示，保存原执行会话、审批归属会话、来源身份及 host 实例。重启后仅原身份可读取和回答，提交时重新检查会话归属与控制权限。

原 host 已中断的问题通过现有问答面板重新回答，明确显示恢复提示。答案与问题作为用户上下文原子写入归属会话，原记录同时标记已处理；取消也持久记录。不会恢复旧 Promise、自动重新调用工具、启动模型或解除 Plan 只读模式。用户发送后续消息继续。原执行租约尚未到期或会话在另一处运行时拒绝恢复提交（租约通常最多 30 秒），保留原记录。

正常问答继续等待原工具回调；响应先保存审计记录，避免回复重复处理。正常 host 退出保留未答问题，明确用户取消清理问题。未提交的输入草稿已由 [问题答案草稿](question-answer-drafts.md) 交付；普通非 host TUI 持久问答见文末后续规格。跨身份接管与自动续跑不在本范围。

验证：新增 question-recovery 定向测试，已有 attached-workflows 问答用例，一个独立 host SIGKILL + 附着 TUI PTY 脚本。覆盖错误身份/会话、重复提交、旧租约保护、恢复答案留存及 Plan 只读；最后类型检查与构建。

实现与验证记录见 [问题恢复验收](../validation/question-recovery.md)。附着界面在租约保护导致提交失败时保留当前答案，供用户手动重试；退出该重试面板不代表已经保存。

后续普通非 host TUI 的独立范围与验证见 [普通问题恢复](local-question-recovery.md)。上述原切片范围保持不变。
