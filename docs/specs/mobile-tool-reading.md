# 手机工具调用与失败记录

手机任务历史应能辨认工具名称和失败状态，并阅读助手实际请求的工具调用参数。当前 host 已在有界消息页提供工具元数据，手机解析时将其丢弃；本片仅补齐只读阅读，不增加执行、重试工具、上传、推理内容或新协议。

## 行为与边界

- 历史列表保留可选工具名称、失败标记及最多 32 条调用的 ID/名称预览。旧 host 或旧缓存没有这些字段时仍可阅读。列表与离线缓存不保留调用参数；有界预览数量不冒充完整调用总数。
- 工具结果显示具体名称，失败明确标注。助手消息即使没有文本，只要有调用预览，也提供“查看工具调用”。全部工具参数通过既有 `messages.content` 的 `toolCalls` 字段按需读取，并说明只读、不会执行。
- 复用现有消息正文页和 UTF-16 安全分页，每次请求最多 8192 单元、仅保留当前段。页面标题、翻段、回到开头和重试始终绑定同一字段；不把调用参数当作普通正文或对部分 JSON 做解析后重排。
- 内容字段只允许 `text` 或 `toolCalls`。关闭、换任务、后台、失效连接和撤权沿用现有内容失效规则，迟到回复不得恢复旧详情。离线禁止翻段；普通正文和消息搜索跳转维持原行为。

## 实现与验证

修改 `apps/mobile/src/controller.ts`、任务消息行和现有正文页，保持直接类型与独立异步读取身份，不建立通用工具执行入口。先以 controller 定向测试证明元数据丢失、工具调用字段不能读取；再补最小实现。

定向验证覆盖：无文本的调用消息、工具失败元数据、有界预览不缓存参数、长中文/emoji 参数跨段完整重组、普通正文回归、迟到回复及关闭/后台/换任务隔离。真实 shared host/SQLite 与加密设备连接验证 view 权限读取、其他任务与撤权拒绝；必要移动类型检查和双平台 JS 导出由集成阶段执行。原模拟器界面验证另记，Android、真机、完整读屏和发布性能不由自动化用例替代。
