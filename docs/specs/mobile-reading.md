# M0：有界长消息阅读

本轮仅修改 `apps/mobile/`、`tests/mobile-*.test.ts` 和移动端文档；沿用 `codex/harness-client-reboot`。TUI 另一分支正在修改 core/runtime/TUI，保持这些目录以及共享协议、根 TODO、依赖和启动脚本不变。

在任务历史的长消息预览下提供“阅读全文”，打开原生独立详情页。复用已有只读 `messages.content`，始终限定当前授权会话、消息 seq 和 `field: text`；不增加通用 RPC 入口或任何变更方法。每次读取最多 8192 个 UTF-16 单元，只保留当前段，不缓存正文到磁盘。固定 8190 单元分段，额外读取边界字符，避免把 emoji 代理对拆开显示；支持上一段、下一段、回到开头和重试。

校验响应编码、长度、总长度和游标一致性。失败时显示错误与重试；旧段在翻段期间清空，避免把旧正文标成新段。离线内容明确标记旧快照，不能翻段；重新连接、切换任务、关闭详情、后台、撤销及失效连接会清除详情并隔离迟到回复。导航只携带无正文的路由，不携带配对凭据或消息内容。

必要验证：边界/异常分页纯函数测试；加密 controller 的关闭/后台/切换竞态；扩展现有一条真实 Runtime/SQLite/加密只读恢复测试，验证长正文分段与撤权清理。只跑受影响移动端测试、移动端类型检查和生产 JS 导出；不跑 TUI 基准或全量测试。M0 真机、发布性能和长期内存验收继续保持开放，不把本轮当作 M1 交付。

## 使用

1. 按 [M0 指南](../mobile.md) 连接主机、取得查看授权并打开任务；日常预览仍使用原有 `pnpm dev:sim`。
2. 超过历史预览长度的消息下点“阅读全文”；正文支持选择和复制。“上一段”“下一段”“回到开头”按需请求当前段，失败可重试。
3. 短暂离线可看当前旧段，翻段禁用。重新连接或退到后台后返回任务重新打开；切换任务、关闭详情及撤权也会清除正文。

详情仅展示文本；图片、推理和工具结构化内容仍按后续阶段推进。分段保证有效 UTF-16 代理对完整，不声称保持所有组合字符或多码点 emoji 序列在同一段。
