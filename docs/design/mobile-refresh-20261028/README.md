## 设计约定

系统正文字体；正文 16/25，辅助信息 13/20，标题 22/30。间距采用 4/8/12/16/20/24；主页面横向 20，消息横向 16；按钮至少 48 dp。Paper/Ink/Beam 延续品牌，浅深色使用语义背景/文字色；黄色仅用于主要操作和重点标记，文字保持深色对比。任务列表使用分隔行，用户消息为浅底气泡，助手消息开放排版，工具默认折叠。无新增依赖、后台协议或模型请求。

输入栏独立于消息列表，以键盘可见区域为边界；原生 TextInput 保持 defaultValue，正文增长到 144 dp 后内部滚动。正常发送/待发队列为主动作，补充到下一模型轮为单独明确动作。结果未确认时保留原文与核对入口。审批详情可展开，未阅读详情不能直接允许。

消息页仅在位于底部时跟随新内容；读历史不抢滚动位置，提供回到最新。任务工具通过独立页面组织，审批与停止仍在对话可见区域。通知入口位于设置，说明暂缓，不改注册与关闭能力。

## 验证边界

React Native KeyboardAvoidingView / TextInput / FlatList 官方文档作为键盘和列表实现依据。原生截图检查至少包括连接、任务列表、长中文对话、工具、设置、浅深色和输入。自动化覆盖草稿、回执、权限和恢复；Android 真机中文 IME、锁屏、网络切换等由用户安装 Release APK 后验收。
