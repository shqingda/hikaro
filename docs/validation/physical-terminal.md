## 2026-11-01 复验：输入法、鼠标与主题

入口 `pnpm check:ime`（构建 `2b60d8a`）。用户反馈：输入法五项、鼠标拖选复制与点击、亮暗主题显示、`NO_COLOR` 均“没问题”。终端与输入法的名称和版本未提供，不补写推测值。

用户报告的四个问题与处理：

| 问题                                                                 | 原因                                                                    | 修复                                                                                                                      |
| -------------------------------------------------------------------- | ----------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------- |
| 滚轮上滚看不到“↓ N more lines”                                       | 提示在顶部标题下的灰色行，几乎看不到                                    | 改到对话区底部、输入框上方，用强调色                                                                                      |
| 系统亮暗切换后，用户消息底色不变                                     | 未开启终端外观通知（mode 2031）                                         | 开启通知，并在终端重新获得焦点时重读背景色                                                                                |
| 拖入图片后另起一行显示 chip；Ctrl+- 撤销不符合习惯；点击打开外部应用 | chip 单独占一行                                                         | `[Image #N]` 内联在文字中并整体删除；Ctrl+Z 撤销；点击在终端内预览（sips 缩放后用半块字符绘制），Esc 关闭，O 用“预览”打开 |
| 不清楚“保存默认”是全局还是项目                                       | 默认存于 `~/.hikaro/model-selection.json`（全局），但只有 Ctrl+S 才保存 | 与 Pi、Claude Code、opencode 一致：选中模型即保存为新会话的全局默认，已有会话保留各自模型                                 |

以上修复有自动测试和真实 PTY 走查（粘贴→内联 token→点击→预览→Esc），尚待用户在真实终端复验。
