# 手机图片与文件差异验收 · 2026-10-21

本轮完成按需图片阅读和只读文件差异，规格见[阅读范围](../specs/mobile-inspection.md)。在现有 iPhone 18 Pro／iOS 27.0 开发客户端运行源码，通过 Codex 内置浏览器的 `localhost:3200` 操作原生界面。使用隔离 shared host、SQLite、Miniflare TLS relay 和临时 HTTPS 隧道；只授予设备本任务 view 权限，没有使用真实账号或生产 relay。

验收源码现已固定为 `bbf36a6`（包括共享 diff、只读 RPC、阅读模块与原生界面四个提交）；之后的提交仅记录文档和截图。

## 已验证

- 实际 host 集成：100,000 字节图像数据分三段完整读取；5,000 行中文/emoji 差异跨页完整重组，包括无末尾换行标记。读取不改文件，其他任务、回退写入和撤权后读取均被拒绝。该测试验证传输字节；原生显示另用两张有效 PNG 验收。
- 六项阅读模块单测：按需读取、格式/MIME/容量/游标拒绝、关闭/换任务/撤权时迟到回复失效、通知到达前再次检查权限、Unicode 分页和快照身份变化、旧主机明确禁用差异而保留图片能力。既有内容分页两项与 TUI 无末尾换行一项定向回归通过。
- 移除异步回复后的 `canAct` 检查时，权限竞态用例按预期失败；恢复源码后通过。没有跳过断言或降低门槛。
- 原生 iOS：查看两张图片、放大与适屏、下一张/上一张、转后台再回来返回任务且不恢复图片；打开文件列表、查看红色删除与绿色新增、中文和 emoji、返回列表再打开；撤销配对后退出阅读并显示配对失效。
- 根/移动类型检查、CLI 构建和 iOS/Android Hermes 导出通过。布局修复后重新完成移动类型检查及双平台导出，没有重跑不受影响的全量测试或性能基准。

## 发现并修复

横排 `@expo/ui` 按钮所在 Host 缺少宽度，导致图片缩放和切换按钮不可见。为每项提供可伸缩宽度后，实际点击与图像变化通过。图片增加原生可访问元素标记和标签；这不等同于 VoiceOver 全流程验收。

fixture 最初使用 `/tmp` 符号链接路径，安全文件操作拒绝打开父目录；改用其真实 `/private/tmp` 路径生成修改记录，没有改变安全校验。预览 AX 有动画延迟，最终以新截图和可见控件共同核对。一次错误的辅助 RPC 方法被协议拒绝，后续用 fixture 已有 revoke 命令完成撤销，未修改产品权限接口。

隔离设备已撤销，host、relay 和隧道已停止；本轮剪贴板已清空，临时目录移入废纸篓。保留原有模拟器、Metro 和 Codex 预览。

## 剩余范围

Android 原生与物理设备、键盘/IME、VoiceOver/大字体、通知、生产 relay、签名分发和发布性能仍待验收。图片预览仅提供当前阅读，不包含拍照/相册导入或持久缓存。TUI 分发草稿仍是 cf57c46，本轮新增协议和共享 diff 代码须纳入后续候选包验收，不能沿用旧包证据。
