# 回退后重做

2026-10-22。`/changes` 选择 reverted 记录后可选择 Reapply this edit，再明确确认。文件当前内容必须精确匹配原编辑之前的内容（新建文件则必须仍不存在）；存在后来修改时拒绝覆盖。

重做复用文件安全写入和快照日志，生成新的 committed 记录，可再次回退。原记录保持 reverted，保留历史。runtime 沿用只读计划、运行中任务、会话 lease、取消/退出和持久结果消息约束。附着入口只在 host 宣告 `changes.redo` 时显示操作；不增加任何只读权限。

类型检查、构建、12 项变更/面板检查及既有 PTY 场景通过。新增定向逻辑覆盖编辑/新建文件的回退后重做、新记录可回退及后来修改冲突；PTY 覆盖取消重做确认不改文件，以及确认后恢复原修改。

附着 TUI 后续验收通过：实际构建 host 宣告 changes.redo；终端取消确认不修改文件，确认后恢复中文内容并生成新的 committed 记录；RPC 可回退该新记录，随后存在外部编辑时重做拒绝且保留外部内容，Ctrl+D 正常退出。用例为 tests/attached-redo-pty.test.ts，没有重跑无关套件。

此改动晚于已发布 v0.1.0，属于下一版本；不修改已发布包和标签。批量/按轮聚合以及 Shell/第三方修改追踪仍未完成。
