# 默认中转与六位码配对 · 2026-10-29

## 实现与部署

用户要求跳过网络稳定性预验证，直接实施。本轮没有进行大陆可达性或长时间网络稳定性测试。

- 默认 relay：`wss://hikaro-relay.shqingda.workers.dev`，通过本机 Wrangler 部署；初次部署版本 `ac2d531e-3c18-46cb-a386-aa672366f8ce`。部署日志：`artifacts/validation/pairing-20261029/deploy.log`。随后仅配置服务端内部密钥，不将它交付客户端。
- `/pair` 自动注册宿主并生成二维码、六位数字码；五分钟有效，新码替换旧码。手机生成自己的密钥，双端显示同一验证指纹，电脑明确允许后手机保存连接。
- 首次成功加密握手才将待配对设备转成长期设备，手机取消或未保存不会永久占用配对名额。任务仍单独通过 `/share` 授权。
- 手机先尝试配对时记录的私有 IPv4 地址，再回退默认中转；共用现有加密与权限处理，LAN 不发送中转 bearer token。端口 43187 无法监听时保留中转路径。
- 首次配对需要中转短码发现；已配对设备可以走 LAN。局域网地址变化需重新配对更新地址。未引入 mDNS 或 Tailscale。
- 复用原 relay 配置创建了通知队列，但未配置手机推送项目、设备 token 或开展通知验收。通知仍暂停。
