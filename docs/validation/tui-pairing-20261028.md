# TUI 内手机配对 · 2026-10-28

## 用户流程

正常启动 `hikaro`、`hk` 或当前仓库的 `pnpm start`，在 TUI 输入 `/pair`。首次由界面询问已部署 relay 地址及隐藏输入的 bootstrap 密钥；用户取消时停留在原有本地会话。成功生成配对码后，当前终端自动启动或复用共享任务主机、连接 relay，并显示全屏二维码；Tab 切换配对码，Esc 返回任务。终端太小时明确提示放大，不展示裁切后的二维码或不完整凭据。

手机扫码后在当前 TUI 明确确认设备，默认选项为拒绝。配对不会自动授权已有任务，仍使用 `/share DEVICE_ID view|control|off`。配对配置复用原有文件和 Keychain，不写入聊天记录或日志，bootstrap 输入不回显。本轮不部署 relay，也不改变设备认证协议和权限判断。

后续普通启动复用配置，只需一个终端。保持窗口开启供手机接续；退出关闭本窗口启动的桥接和主机，外部独立主机不由本窗口关闭。原有分进程命令保留为高级入口。首次切换前后检查活动任务和后台操作，避免中断工作；草稿和显示设置沿用原有记录，已主动清空的共享草稿不会被旧草稿覆盖。

原 `--serve` 无配对配置时，错误改为指向 TUI `/pair` 的中文提示，不再向用户暴露 `remote.json` 的 ENOENT。
