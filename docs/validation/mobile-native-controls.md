# 原生手机控制验收 · 2026-10-21

本轮在 Codex 内置浏览器的 `http://localhost:3200/` 操作现有 iPhone 18 Pro／iOS 27.0 原生开发客户端，验证 `cd246a5` 的审批、停止、队列恢复和编辑。使用隔离 shared host、SQLite、Miniflare TLS relay 与临时 cloudflared HTTPS 隧道；工具为实际本机进程，模型为 demo provider。没有更改系统证书、辅助功能授权或真实账号，没有创建/重装模拟器。

## 已通过的原生流程

| 流程 | 原生操作 | 独立结果核对 |
| --- | --- | --- |
| 拒绝审批 | 展开完整命令和参数，点击拒绝 | 历史保存 `Permission denied`；目标文件未生成 |
| 允许审批 | 展开另一条隔离写入命令，允许这一次 | 文件内容为 `approved`，运行 completed，审批清空 |
| 取消停止确认 | 批准运行实际 sleep 进程，点击停止后选择继续运行 | 原 PID 仍存活 |
| 确认停止 | 再次打开确认框并停止 | 原 PID 消失，主机 busy=false、runStatus=cancelled，历史含 `[Cancelled]`；手机显示“已停止”和已处理回执 |
| 身份恢复边界 | 确认其他身份的恢复项 | 主机拒绝 original client identity，项仍待确认，未启动任务 |
| 本机恢复 | 确认手机身份自己的恢复项 | 状态改为 Pending next model turn，busy=false；其他身份项仍未确认 |
| 原生编辑保存 | 原生菜单粘贴追加中文；返回时选择继续编辑，再点击保存 | 未保存时主机原文不变；保存后完整追加文字进入主机队列，手机显示确认修改 |
| 放弃编辑 | 再次追加不同文字，返回时明确放弃修改 | 返回任务；主机保留前次已保存文字，不包含放弃部分 |
| 后台释放 | 打开管理页，从电脑提交要求，确认尚未进入历史，再按 Home | 暂停要求及已确认手机指令各进入历史一次；其他身份项未消费；运行 completed |
| 回前台 | 从主屏重新打开 App | 显示管理锁已释放，要求重新打开；没有自动再次取得管理锁 |

恢复数据由隔离 SQLite 中的两个持久项构造，再重启测试 host 加载；不把它称为本轮真实崩溃验收。主机后台释放后的历史分别包含一条“验证手机转后台后继续”和一条已编辑手机指令，未确认的其他身份文本为零条，队列只剩其他身份项。

## 发现与检查

首个辅助 CLI 连接使用默认 30 秒请求期限，等待原生点击时超时；其超时不表示工具执行成功或失败。随后通过文件、持久 `Permission denied` 结果及原生已处理回执核对实际拒绝。长运行验收改用观察原始回复的辅助连接，单次人工流程有 180 秒截止时间，没有修改产品请求超时。SQLite worker 不支持继承 `--input-type=module`，改为执行临时 `.mjs` 文件准备数据，未修改存储代码。

预览的 AX 位置有时晚于动画/滚动后的画面，导致定位点击未命中；重新观察截图并点击真实按钮后，以界面和 host 内容共同核对。原生粘贴、保存及两种返回确认最终均通过；这些操作不代替键盘输入或 IME。

发现队列详情会显示先前停止操作的全局提示。本轮只调整该提示的可见条件：当前项发生错误，且用户在本页主动点击核对回执后才显示；换项或错误变化会重置。核心命令与生命周期没有改动。原生流程证据来自该显示调整前的 `cd246a5`；提示调整经过源码审查、根/移动类型检查和双平台 Hermes 导出，未声称重新完成上述原生操作。这个可逆显示修改未增写镜像测试，未重跑未受影响的全量或 host E2E。

测试设备已撤销并在手机显示失效。host、relay 和临时隧道已停止；测试剪贴板清空，临时目录移入废纸篓。保留原有模拟器、Metro 和 Codex 预览。
