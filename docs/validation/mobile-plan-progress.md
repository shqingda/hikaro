# 移动端计划进度（只读）· 2026-10-24

## 结果

任务页新增“查看计划进度”，打开只读的“计划进度”页，显示已批准计划每一步由模型报告的状态（未开始、进行中、已完成、受阻、已跳过）及备注，页首说明这些状态不代表已验证。数据来自既有的只读方法 `plan.read`：新 host 附带 `progress`，见 [TUI 计划进度](plan-progress.md)。没有正在执行的计划时提示“没有正在执行的已批准计划”；旧 host 不含该字段时提示升级电脑端，不猜测状态。

移动端白名单新增 `plan.read`。host 按既有会话角色检查，“仅查看”授权即可读取。该页面不发送 `plan.set`、`plan.execute`、`prompt` 或 `steer`。关闭页面、断开连接或切换任务后，迟到的响应会被丢弃。每一步作为单个读屏元素，朗读“第 N 步，状态：内容”及备注。
