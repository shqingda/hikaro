# 从任务列表返回离线任务

2026-10-23。修复任务列表在断线后禁用“返回正在查看的任务”的可达性缺口。任务页原本支持离线快照和本机草稿，但用户一旦退回列表，就无法再从此入口打开当前任务。

## 行为与边界

- 在线返回行为保持原状。离线、重连中或连接失败时，当前 `session.id` 必须匹配已加载的 `composer.record.session.id`，才能从列表返回任务。草稿正在保存或保存失败不锁住恢复入口，原文仍可查看并重试保存。
- 有消息时显示“查看离线任务与草稿”，没有消息时显示“查看本机草稿”；提示离线内容可能过时、草稿不会自动发送。恢复连接期间单独显示“正在恢复连接”。
- 点击时读取控制器当前状态，防止后台、解绑等状态变更后使用旧的可点击状态。其他任务行、分页和发送的原有在线权限要求保持不变。
- 控制器在恢复身份时先清空外层状态；本机快照与草稿任务不匹配时不显示该快照。仅有快照时，控制器为其创建同任务的空草稿，因此仍能进入阅读。后台、撤销、连接锁定与移除会清空可见任务；本次没有改变这些机制。

覆盖：恢复离线快照并编辑/持久保存草稿；禁止离线切换其他任务和发送；仅有快照时生成匹配空草稿；清除缓存后仍可返回草稿；连接失败保留草稿并拒绝其他任务快照；重连中可返回，后台和移除后不可返回；草稿缺失、加载中或任务不匹配时禁用；身份恢复等待中不使用上一份内存草稿。

## 其余原生验证范围

1. 在线打开任务并等待历史与草稿加载，返回任务列表，再断开电脑连接。列表应显示离线文案；其他任务不能点击，当前离线任务入口可点击。
2. 返回当前任务，确认显示原有缓存与草稿；修改草稿后确认保存，发送仍禁用。返回列表，再进入一次，草稿保持。
3. 清除历史缓存后返回列表，入口改为“查看本机草稿”，仍可进入。恢复电脑连接后不自动发送。
4. 切到后台、恢复时或移除连接后，不得通过旧入口显示上一配对的任务。真实辅助技术焦点、大字体、iOS/Android 原生点击与安装包更新尚未在此切片验收。
