# 手机搜索恢复链路 · 2026-10-22

当前实现通过真实 shared host、SQLite、加密移动连接及远程权限分发核验。沿用既有主机重启恢复用例，仅增加搜索断言，不重复整套验收。

- view 权限手机搜索 24,000 字符之后的中文及 emoji，返回正确消息及命中摘要，证明搜索覆盖完整正文而非列表预览。
- 从结果读取原消息分页，保持已有大正文读取边界。
- 重建手机控制器、重启主机后，仍能搜索同一消息；恢复期间不重发任务选择命令。
- 电脑撤销任务权限后，清空搜索结果、正文和历史缓存，后续搜索拒绝。

命令：`pnpm exec vitest run tests/mobile-controller.test.ts -t 'restores the same granted host task'`。1 项通过；其余 16 项由名称过滤而未运行。既有用例验证主机恢复、正文读取和撤权；本轮补充消息搜索经过完整传输白名单的证据。
