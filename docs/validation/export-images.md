# 可移植图片导出

2026-10-21。普通与附着 TUI 的 `/export` 共用 runtime 导出：Markdown 旁生成同名 `.assets` 文件夹，通过相对链接引用会话中实际保存的 PNG/JPEG/WebP/GIF 图片。文本附件原本包含在消息正文中的内容继续保留；任意工具产物和外部文件引用尚未打包。

图片每次读取 65,536 个 base64 字符，逐块写入私有文件；生成路径不使用模型提供的文件名。成功后才发布 Markdown，失败清除临时 Markdown 和本次图片目录。未知媒体类型在正文明确标为不可导出。

类型检查、构建及两项导出定向用例通过：全历史分页/隐藏 thinking 默认排除，以及跨块图片与原始字节完全一致、相对引用、无 provider 私有数据。
