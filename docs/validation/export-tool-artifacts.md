# 工具产物可移植导出验证

2026-10-23。普通与附着 TUI 的 `/export` 共用 runtime：在原 Markdown 和图片之外，导出当前会话 `tool.end` 明确引用的工具结果及一层日志依赖。实现契约见 [规格](../specs/export-tool-artifacts.md)。

## 已验证行为

只获取一次事件水位；消息和工具产物引用均限定在该水位内。工具引用分页每次最多扫描 100 条 `tool.end`，没有引用的空页也继续推进。历史新增事件不混入当前导出，重复资源跨页只复制一次。

产物文件必须属于当前会话的宿主 `artifacts`/`outputs` 目录，文件名符合既有白名单。共享 helper 仅规范化可信 home；候选路径的父目录和文件都经过原生无符号链接读取。跨会话、外部路径、父目录/文件符号链接及含 NUL 的引用被拒绝，不能降级为普通路径读取。

JSON 结果只导出 `text` 和布尔值 `isError`，不复制原始 `data`、`providerData` 或未知字段。已知 `data.artifact` / `data.process.artifact` 可以发现一层同会话日志；不跟随嵌套 JSON，不解析正文路径。JSON 曾作为依赖被拒绝后，若后续有直接事件引用，仍可正常导出。

工具资产每件源文件最多 16 MiB；最多处理 100 个候选；累计源读取和工具资产写入各最多 64 MiB。测试使用实际 16 MiB 文件及 64 MiB 累计数据验证边界。预算后仍列出未打包资源，说明未检查的 JSON 内部依赖；不把日志截断后当作完整文件。已打包资源附相对链接、实际字节数和 SHA-256。

缺失、路径拒绝、格式无效、超限分别显示固定说明；不会把底层异常及内部路径扩写进清单。安全读取程序故障和输出写入失败使导出失败。实际测试在第一件资产写入后注入 helper 故障或文件系统 `EEXIST`，确认本次临时文件/资产目录被清理，早前导出仍保持原样。

- 首个 RED 用例要求一个投影 JSON 和两个日志；旧实现得到 0 个资产，明确复现工具产物遗漏。
- 先作为嵌套 JSON 拒绝、后作为直接引用的回归先得到 1 个资产而非 2 个，修复去重状态后通过。
- NUL 引用回归先得到 20,315 字符的存储响应。SQLite `length(text)` 在 NUL 处停止，不能独立作为长度边界；加入 BLOB 字节长度与 NUL 检查后，输出仅保留无效引用标记。
- `pnpm exec vitest run tests/export-tool-artifacts.test.ts tests/rpc-library.test.ts tests/session-settings.test.ts tests/attached-navigation-pty.test.ts`：4 个文件、36 项测试通过，2026-10-23 19:54（Asia/Taipei），耗时 4.69 秒。其中新增导出文件包含 14 项测试。
- `pnpm typecheck`：通过。

附着导航 PTY 测试启动真实本地 host 和附着终端，在 `/export` 成功后读取实际 Markdown、相对 JSON 和日志，确认可见字段投影以及完整中文日志。输入数据是隔离会话 fixture；没有模型调用或外部文件授权。普通入口由相同 runtime 定向测试覆盖，不把这次证据称作普通终端人工验收。原隐藏 thinking、图片跨块导出和消息 provider 私有字段排除的回归一起通过。

导出模块仅在执行 `/export` 时动态加载，未新增 runtime 顶层导入。初次定向阶段未重建 dist。后续独立审查发现并修复下面两类边界；整合全量检查、安装包验证和性能证据由主任务统一记录。

## 独立审查修复

取消原本可能发生在最后工具清单写入或最终文件关闭期间，导出仍继续发布。两个真实 runtime 回归分别拦截最后 `FileHandle.write` 和最终 `close`，在异步操作期间关闭 runtime；RED 均表现为导出成功返回，而不是拒绝。修复后在工具清单完成及 Markdown 句柄关闭后复核生命周期，重命名前作为发布提交点。两种取消均拒绝导出，删除本次临时文件/资产，保留旧导出。

原生读取可能在读取全部允许字节后返回 `ESTALE` 或 `EIO`，只对成功读取计费会使连续失败绕过总预算。两个轻量故障注入回归分别模拟这两种错误，RED 均表现为进行了第 5 次读取，而预期只允许 4 次 16 MiB 读取。修复后仅对 `read-failed` 按本次读取上限保守计费；缺失、拒绝与读取前超限不扣字节预算。

最终同组定向验证：4 个文件、40 项测试通过，2026-10-23 20:05（Asia/Taipei），耗时 3.98 秒；其中新增导出测试为 18 项。`pnpm typecheck` 和 `pnpm build` 均通过。两项审查问题的修复与回归已由独立审查者复核，无剩余阻断项；未重复运行全量或性能基准。

## 保留边界

这次不是通用附件管理或任意外部文件打包。文本附件继续保留在消息正文，图片继续使用既有导出；文件没有历史内容摘要，清单 SHA-256 证明本次导出字节，不证明文件从创建到导出从未变化。

私有字段排除通过明确投影实现，不声称能识别用户可见文本/日志中本来就包含的秘密。失败清理覆盖正常抛错路径；进程强制终止后的临时文件回收仍未承诺。
