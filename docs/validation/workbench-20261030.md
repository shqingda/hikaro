## 性能

在同一 macOS arm64 主机串行运行，期间未并行构建或测试。基线用 `git archive 02f4449` 构建在临时目录并共享当前依赖；两份源码所在目录不同，因此不把小幅差异解释为显著提升或退化。启动均为 3 次预热、30 次测量；流式每场景 1 次预热、3 次测量。

| 指标         |      基线 |    工作台 |
| ------------ | --------: | --------: |
| 原生启动 p95 | 167.87 ms | 168.14 ms |
| 原生输入 p95 |   2.78 ms |   2.14 ms |
| 附着启动 p95 | 160.97 ms | 161.29 ms |
| 附着输入 p95 |   0.88 ms |   1.05 ms |

`bench:check`、`bench:attach:check`、`bench:stream:check` 均通过。启动差异分别约 0.27 / 0.32 ms，没有显示出实质退化。输入低于既有 16 ms 门槛；启动 200 ms 仍按既有规则为参考值。

原生和附着模式的普通输出、100/1000 段突发、Markdown、万条历史场景全部通过 33 ms 流式门槛；最慢场景 p95 为 **25.71 ms**。边运行边输入场景 p95 为 1.44 / 1.43 ms，滚动与取消检查通过。计时端点是本地 provider 到 PTY 输出，不是网络模型延迟或显示像素。

指标与构建哈希见[性能摘要](workbench-20261030/performance.json)，完整原始报告在本地 `artifacts/workbench-{native,attached,stream}.json`。测量后最后补丁只修正 Pi 内嵌工具取消标签和 `file_path` 目标；最终构建的 CLI JavaScript 文件哈希与测量版本一致，变化项是 `pi-extension.mjs` 及重新编译的两个原生 helper（二者源文件未改）。最终构建再次通过全量与真实 Pi smoke，性能记录不冒充整包哈希完全相同。

## 明确保留的未验项

Computer Use 工具明确禁止访问 `com.apple.Terminal`，未绕过此限制。因此真实中文 IME 候选窗位置、实际终端字体及复制选择仍需人工验收。已通过的 PTY/光标标记/鼠标映射和组件预览不能替代这些项目。

没有运行真实账号模型、30 分钟稳定性或全平台终端矩阵；本轮不声称已完成这些验收。用户偏好及数据格式无迁移。
