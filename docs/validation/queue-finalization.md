# 队列收尾竞态验收（2026-10-21）

问题：最后一个 prompt 的 completion 已兑现，drain 仍异步执行一次空队列读取，调用方紧接手动工具会被 busy 拒绝。手动工具的 finally 又无条件调用 drain，空队列也会短暂占有执行状态，导致随后 compact 被拒绝。

修复：没有待完成队列写入且没有可调度任务时，drain 入口直接返回；每项执行结束后，如果没有待完成写入且队列为空或处于 hold，直接结束循环，在同一微任务内释放 draining。保留队列写入保护，不在仍有后续任务时开放手动执行；恢复待确认项不自动运行。

验证过程：原连续操作用例和新增双任务用例先失败。第一轮修复使 prompt 收尾通过，并暴露手动工具结束后的同类空 drain；第二轮修复后全部通过。未添加等待或放宽断言来掩盖竞态。
