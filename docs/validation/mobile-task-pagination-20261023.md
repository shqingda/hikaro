# 手机任务分页与离线返回 · 2026-10-23

在原有 iPhone 18 Pro / iOS 27 模拟器上，用隔离 demo host、真实 RPC 和加密 relay 连接验收。保留原模拟器、Metro 与 localhost:3200 预览；51 项任务均为合成测试数据，仅授予查看权限，没有调用真实模型或发送草稿。

## 分页缺陷与修复

超过 50 项任务后，第一页底部本应出现“上一页／下一页”，原生屏幕却留下空白。两个 Action 直接位于横排容器，SwiftUI Host 只测量高度而没有可用宽度。给两侧分别包裹 `View flex:1` 后，按钮可见；沿用正文分页页面已有布局，不修改权限、加载或页偏移逻辑。

现场先保存[修复前截图](mobile-pagination-20261023/before.png)，再验证：

- [第一页](mobile-pagination-20261023/page-one.png)显示任务 51–02，上一页禁用、下一页可点击。
- [第二页](mobile-pagination-20261023/page-two.png)仅含任务 01，上一页可点击、下一页禁用；返回第一页再次看到任务 51，随后还能回到第二页。
- 打开任务 01 后读取两条既有消息；断开隔离 relay，列表两侧分页均禁用。
- [离线列表](mobile-pagination-20261023/offline-list.png)仍可点击“查看离线任务与草稿”。[返回详情](mobile-pagination-20261023/offline-return.png)显示同一任务、两条缓存消息和未发送的 `515151` 草稿。

本轮先尝试英文桥接按键，iOS 中文候选仍处于组合状态，Escape 后未形成草稿；正式返回验收改用可核对的数字和换行。该结果不证明完整中文输入法或高速键入已通过。预览的大幅滚轮手势也会误触任务；以较短滚动完成实际分页操作，不用直接改页面状态替代点击。

移动类型检查通过，日志 `/tmp/hikaro-mobile-pagination-typecheck.log`。另一代理只读审查布局修改，无阻断发现。新 Android 包、Android 运行、物理设备、大字体及完整读屏仍待验证；当前旧 APK 不包含本修复。
