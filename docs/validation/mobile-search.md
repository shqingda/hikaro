# 移动端消息全文搜索

2026-10-21。任务详情增加“搜索消息”，使用 host 的 `messages.search` 查找当前会话完整正文，包含未加载到手机的历史。支持中文关键词、前后分页、打开既有正文阅读页；结果只驻留内存。需要 host 支持搜索与正文读取，旧 host 隐藏入口。

延续阅读模块的会话、连接及请求代际检查；切换任务、断开、退出搜索时清除结果，迟到响应不能恢复旧任务数据。搜索按需触发，每页最多 20 项；接口响应有结构和游标校验，不预取全量历史。

已通过移动类型检查、8 项阅读模块测试和 iOS/Android Hermes 导出。新增用例覆盖请求会话和上限、跨任务迟到响应、旧 host 及无进展游标。host 的实际搜索/正文链路见 [TUI 验收](message-search.md)。

原生页面点击、软键盘和真机尚待验收；导出通过不等于这些项目完成。
