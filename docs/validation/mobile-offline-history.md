# 手机离线历史缓存

2026-10-21。手机重开后除恢复未发送草稿外，现在可查看上次任务的一页消息。每个配对身份只保存一份快照，最多 20 条、单条预览最多 20000 字符，序列化总长最多 2000000 字符；图片和完整附件不缓存。缓存不恢复控制权限，也不触发发送。

主机、设备、公钥与 relay 共同隔离缓存；旧任务与当前草稿不匹配时不显示。移除连接、设备撤销和主机返回的任务授权/选择变化清理相应缓存。缓存写入与凭据清理共用串行队列并检查状态版本，防止迟到写入复活旧内容。任务页提供清除历史缓存入口，保留草稿与电脑任务。

验证：mobile-controller 16 项通过，包括离线重开/只读、不自动发送、保留草稿的缓存清理、其他身份/任务与超限缓存拒绝、移除连接时的在途写入，以及真实 shared host 的恢复和授权撤销。根项目和 mobile typecheck、iOS/Android Hermes export 通过。原生 SQLite 实际重开与真机操作仍待端到端验收，不以控制器测试替代。
