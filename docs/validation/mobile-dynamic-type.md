# 移动端大字体（Dynamic Type）首轮 · 2026-10-24

## 结果

在 iPhone 18 Pro / iOS 27 模拟器的未配对首页，把系统字号设为最大的 `accessibility-extra-extra-extra-large` 后发现两处问题，现已修复：

| 问题                                                                            | 修复                                                                        | 截图                                                                                                          |
| ------------------------------------------------------------------------------- | --------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------- |
| 品牌字标 `hikaro` 在单词中间折成 `hika` / `ro`                                  | 字标属于装饰性品牌元素，限制为单行，放大倍数上限 1.5；标题语义不变          | [修复前](mobile-dynamic-type/before-ax5-wordmark.png)、[修复后](mobile-dynamic-type/after-ax5-top.png)        |
| 通用按钮 `Action` 固定高度 48，长标签被截成 `查看上次任…`，按钮之间几乎没有间距 | 去掉原生按钮的固定高度，最小 48 pt 触控区域改由外层 `Host` 保证，标签可换行 | [修复前](mobile-dynamic-type/before-ax5-buttons.png)、[修复后 AX3](mobile-dynamic-type/after-ax3-buttons.png) |

标语和说明正文继续完整跟随系统字号。曾尝试给标语设 2 倍上限，结果它比正文还小、层级颠倒，因此撤回。`Action` 是全应用共用的按钮组件，此修复同样作用于任务页、审批、停止、搜索等页面，但这些页面本轮**未**在大字体下截图验证。

## 补充：离线任务页（同日）

获得模拟器操作权限后，在最大字号下从首页点击已换行的“查看上次任务与草稿”，打开缓存的离线任务页。标题、离线状态说明、用户与 Hikaro 消息、工具调用预览均完整换行，无截断或重叠，见 [截图](mobile-dynamic-type/after-ax5-offline-task.png)。消息列表很长，本轮没有滚到底部的输入框与操作按钮。

## 验证证据

- 实际模拟器截图：最大字号下字标保持一行；`accessibility-extra-large` 下长按钮完整换为两行，按钮间距正常。验证后模拟器字号已恢复为原来的 `large`。
- 移动类型检查通过；iOS/Android Hermes 导出通过，日志 `/tmp/hikaro-mobile-export-20261024-dynamic-type.log`；`tests/mobile*` 12 个文件、97 项测试通过。
