# 本轮实现与精简 · 2026-10-24

基线 main@5d9f04d。历史测试数量不是本轮通过证据。

## 复杂度与处理顺序

- Runtime（1,351 行）：子任务记录与插件租约执行有独立职责，本轮分离。
- MobileController（1,360 行）：计划、后台任务、正文重复请求代次/身份隔离，本轮统一上下文检查但保持页面各自代次。
- mobile-controller.test.ts（2,043 行）：共享加密 fixture 与真实 host 用例混排，按控制器与 host 场景归组。
- core、RPC、storage worker 均超过 1,000 行；保持既有模块约定，优先处理本轮涉及职责，不做全量搬移。
- 普通 TUI 插件直接执行，附着经过 runtime 租约/历史路径，本轮统一。

## 测试删减与保留覆盖

- performance-build：删除仅搜索产物中 enableCompileCache 字符串的断言；保留真实启动、禁用/不可用缓存与空缓存实际生成文件验证。
- tui-text：同一 sanitize 实现经 re-export 被逐例重复调用；改为一次导出身份检查，保留全部输入/控制字符断言和面板行为。
- 移动用例按职责归组，保留真实加密、授权、回执、重启和迟到响应场景，不按数量删减。

## 验证

测试精简：4 个测试文件、48 项通过；根类型检查与 diff 空白检查通过。测试按控制器与真实 host 分组，36 项移动用例全部保留。

## 后续边界

脱离进程组、provider/资源/MCP/Pi、真机/生产通知/签名与长期性能仍为后续项。

## 插件与子任务整理

子任务记录管理和插件租约执行已分离，4 项原有回归通过。初始化顺序由类型检查与原子任务用例捕获并修复。

插件命令/视图增加协作取消上下文；普通与附着复用 runtime。回归验证取消身份、取消后仍持租约、迟到成功不落盘、真实 host 控制通道和同 ID 不重放。普通命令的结果仍返回会话，插件选择器保留完整结果阅读。Esc 仅关闭，Ctrl+C 显式停止。后台任意可信代码不在强制隔离保证内。

## 修改汇总与观察

新增只读 `changes.review.list/diff`，按持久委派关系恢复子任务树；原始 `FileChange` 和回退方法保持原作用域。普通／附着 TUI 共用来源、任务、运行筛选；手机协商新接口，旧 host 仍读取原记录。

前台 Shell、插件工具及命令／视图在执行前后捕获文本变化，失败和取消也收集。候选上限 10,000，前后快照合计 64 MiB，单文件 16 MiB，单次扫描最长 5 秒；只持久化变化文件。遵守 ignore，排除敏感路径、符号链接、工作区外及自身证据目录。超限、读取失败明确提示。记录描述为执行期间观察，不能证明写入归属，不提供回退；同调用、路径与哈希完全一致时去重。

验证：观察失败／删除／忽略／敏感路径／链接隔离／大小超限；重启后子任务树隔离；附着只读差异；移动能力协商与旧 host；原有普通 TUI 真实 PTY 回退均通过。根与移动类型检查通过。原生在线验收尚未完成。

## 计划执行证据

工具开始时固定 plan/session/唯一进行中 step；没有唯一进行中步骤时保留 plan 但不指定 step。子任务继承委派时的引用，根任务只汇总持久委派树内证据。旧记录不补造引用；原 `recordedEdits` 时间统计只保留兼容用途，不参与步骤关联。

计划读取增加每步可靠修改／观察差异／工具结果与未关联统计。工具结果投影由专用 SQLite 索引读取，最多展示 60 项并明确不完整状态；`plan.evidence` 通过根任务树和 plan 身份复核分页读取输出，超长预览明确截断。普通／附着 TUI、手机均提供按步骤查看差异与工具结果的入口；手机保持只读。

验证：执行期间步骤变化、多个进行中步骤、真实子 agent 继承、重启、任务树隔离、新计划不吸收旧证据、RPC 工具结果隔离；根／移动类型检查与 49 项相关回归通过。两条普通／附着 PTY 计划执行入口通过，普通入口实际打开执行证据面板。
