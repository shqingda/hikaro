# Hikaro 0.4.0

### 安装与升级

```sh
curl -fsSL https://github.com/shqingda/hikaro/releases/latest/download/install.sh | sh
```

已装 0.3.0 的用户运行 `hikaro update`（或 `hk update`）。升级原子切换，保留上一个版本供回退；数据目录 `~/.hikaro` 不变，本版没有需要手动处理的数据迁移。

### 变更

- **运行中插话**：任务运行时直接发送消息即可插话，与 Codex 一致。模型正在思考或输出时，当前回复立即停下（已输出的内容保留），模型带着新消息马上重新回答；正在执行的工具不会被打断，执行完后跳过同一步剩余的工具调用。`/follow` 或 Ctrl+X Enter 改为排队成下一个任务。
- **`/context` 显示上下文用量**：参考 Grok Build，显示已用 / 窗口大小、按类别（系统提示、工具定义、消息、回复预留、空闲）的 100 格分布和离自动压缩还剩多少。设置窗口大小改为 `/context-window [SIZE] [default]`，例如 `/context-window 256k`。
- **图片**：粘贴或拖入的图片变成输入框里的 `[Image #N]`，整体删除，Ctrl+Z 可恢复。点击它在终端内预览，Warp、Ghostty、kitty、WezTerm 显示原始清晰度。图片在粘贴时就复制保存，macOS 截图缩略图消失后仍能发送。离线 demo 也接受图片。
- **交互**：命令补全和 `/help` 由同一份命令表生成；离开底部时输入框上方居中显示可点击的「↓ PageDown」；消息背景跟随系统亮暗切换；选择模型同时设为新会话默认；新增 `/exit`；会话列表标明 Delete Ctrl+D、Rename Ctrl+R；附着模式 `/delete` 打开会话选择器；后台会话需要处理时标题栏提示（Ctrl+O）。
- **修复**：已发送的内容不再被恢复进下一次草稿；Pi 扩展可以正常构建，视图不再少一行；插话与取消严格绑定到对应的运行。
- **清理**：移除手机端遗留、死代码和已被取代的资产与验证原始数据；测试共享 PTY、主机和临时目录辅助工具，去掉重复用例和固定延时。

### 已知限制

- 仅支持 macOS Apple Silicon。没有 Developer ID 签名和公证；install.sh 会去掉下载带来的隔离属性。
- `/context` 用量是保守估算，不是 tokenizer 精确计数。
- 终端内高清图片预览需要支持 Kitty 图形协议的终端；其他终端使用半块字符预览，预览依赖 macOS 自带的 `sips`。
- 真实模型账号闭环、长任务摘要质量、Linux 和更长周期尚未验证。
