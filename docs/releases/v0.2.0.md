## 安装和启动

```sh
gh release download v0.2.0 --repo shqingda/hikaro --pattern '*.tgz' --pattern '*.sha256'
shasum -a 256 -c hikaro-0.2.0-darwin-arm64.tgz.sha256
npm install --prefix ./installed --engine-strict ./hikaro-0.2.0-darwin-arm64.tgz
./installed/node_modules/.bin/hikaro --cwd /你的项目绝对路径
```

同一用户和默认数据目录沿用现有订阅登录；无需 API Key。确实未登录时使用 `/login` 选择 xAI 浏览器订阅授权，再用 `/model` 选模型。

升级前停止使用同一数据目录的 host/TUI/桥接并备份完整数据目录，保留旧安装。回退时先停新版，再使用旧安装及升级前备份。不要让旧程序直接写入新版修改后的数据库。
