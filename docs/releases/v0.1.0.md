## 安装

在空目录下载并校验附件，再安装到该目录：

```sh
gh release download v0.1.0 --repo shqingda/hikaro --pattern '*.tgz' --pattern '*.sha256'
shasum -a 256 -c hikaro-0.1.0-darwin-arm64.tgz.sha256
npm install --prefix ./installed --engine-strict ./hikaro-0.1.0-darwin-arm64.tgz
./installed/node_modules/.bin/hikaro --version
./installed/node_modules/.bin/hikaro
```

最后一条命令以当前目录作为工作区。要处理实际项目，改用 `./installed/node_modules/.bin/hikaro --cwd /你的项目绝对路径`。同一台 Mac、同一用户且未修改 `--home` 时，会沿用已有 Hikaro 数据目录和订阅登录；不需要配置 API Key。若界面提示尚未登录，输入 `/login`，选择 xAI 并完成浏览器订阅授权，再用 `/model` 选择可用模型。

启动后直接输入要求并回车；`/sessions` 切换历史任务，`/search 关键词` 搜索当前会话，`/changes` 查看文件变更，`/export` 导出。Ctrl+C 取消当前运行，Ctrl+D 退出并保留未发送草稿。

0.1.0 发布之后的源码新增了变更 redo、附着模式模型参数快捷设置以及 macOS `/paste-image`；这些尚未包含在上述下载包里。移动端需单独构建安装，不能通过此 TUI tarball 安装。

## 升级与回退

先停止使用同一数据目录的 host、TUI 和桥接，再备份完整 `~/.hikaro`（或指定 `--home`）目录。保留旧安装目录及升级前备份。出现回归时停止新版本，切回旧安装并恢复升级前数据；不要让旧版本直接写入新版本已修改的数据。系统 Keychain 凭据不会包含在普通文件备份里。
