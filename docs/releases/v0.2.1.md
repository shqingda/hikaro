相对 0.2.0 修复：

- 删除会话时同步清理该会话的变更快照和计划缓存，保留分支及工作区文件。

这是 macOS Apple Silicon 自用预览版，需要 Node >= 24.21.0。不包含移动端，也不表示完整目标已完成。真实订阅及网络故障矩阵未在本补丁重跑。

在空目录执行：

```sh
gh release download v0.2.1 --repo shqingda/hikaro --pattern '*.tgz' --pattern '*.sha256'
shasum -a 256 -c hikaro-0.2.1-darwin-arm64.tgz.sha256
npm install --prefix ./installed --engine-strict ./hikaro-0.2.1-darwin-arm64.tgz
./installed/node_modules/.bin/hikaro --cwd /你的项目绝对路径
```

沿用已有 Hikaro 订阅登录，无需 API Key。升级前停止旧 host/TUI/桥接并备份完整数据目录；回退时使用旧安装与升级前备份。
