# Hikaro 0.3.0

### 安装与升级

```sh
curl -fsSL https://github.com/shqingda/hikaro/releases/latest/download/install.sh | sh
```

安装后运行 `hikaro`，或用简写 `hk`。升级运行 `hikaro update`（或 `hk update`）。

- 安装包自带 Node.js 26.12.1，不需要预装 Node、npm 或 sudo。程序装在 `~/.local/share/hikaro`，命令链接到 `~/.local/bin`；该目录不在 PATH 中时，安装脚本会在 shell 配置里补一行，打开新终端后生效。
- 下载会核对 SHA-256，校验失败时已装版本不变。`~/.local/bin` 里同名命令如果不是 Hikaro 装的，安装会拒绝覆盖。
- 升级原子切换到新版本，保留上一个版本，更早的版本删除。正在运行的 hikaro 继续用旧版本，重启后生效。数据目录 `~/.hikaro` 不在安装目录内，升级不改数据；本版没有需要手动处理的数据迁移。
- 此前通过 npm tarball 或源码安装的副本不会被自动替换，`hikaro update` 只作用于 install.sh 安装的副本。

### 变更

- **Pi 互通**：`hikaro --install-pi` 安装或升级 Pi 默认入口。在 Pi 里打开 Hikaro 会按工作目录接回上次的会话并显示最近消息；Hikaro 子进程断开后，Ctrl+D 或 `/back` 都能回到 Pi，草稿保留。
- **补缺**：自定义 provider 可声明图片、上下文和推理能力，界面与请求一致；MCP 连接可查看状态、断开和重连；本地技能与资源显式安装和重载；通用文件附件安全保存和导出，二进制内容不发给模型。
- **修改记录与任务**：按模型运行回退一组修改，或回退到指定位置；子任务和后台终端的结果在 host 重启后保留；计划步骤显示模型报告的进度和对应文件修改。会话快照可预览空间占用后显式清理。
- **修复**：任务图在依赖顺序倒置时误报环；手动 compact/fork 初始化失败留下半成品会话；流式输出暂停时未刷新缓冲文本。
- **性能**：流式 Markdown 只重解析尾部，输出合并延迟 24→12 ms，长 Markdown 流式到终端 p95 约 30 ms；附着模式不再复制流式文本；未变的消息行和状态栏不重绘。

### 已知限制

- 仅支持 macOS Apple Silicon。没有 Developer ID 签名和公证；install.sh 会去掉下载带来的隔离属性。
- 在只装了独立安装包、没有系统 Node 的机器上，Pi 入口启动 Hikaro 需要 PATH 里有 `node`，或设置 `HIKARO_NODE` 指向 `~/.local/share/hikaro/current/runtime/bin/node`。
- 30 分钟稳定性测试（94 轮）通过；真实模型账号闭环、Linux 和更长周期尚未验证。
