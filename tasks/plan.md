用户已批准实施。先修正确性、精简实现、改善性能，再分批补功能；TUI 优先移动随后。完整活动清单在 [TODO](../TODO.md)，当前切片在 [todo](todo.md)。[历史计划](../docs/history/plan-through-20261024.md)保留证据，不表示当前顺序。

## 固定边界

- tutorial 完全不动，包括文件名、位置、内容与格式；批量操作排除，收尾检查清单和 SHA。
- 保留用户能力、独立/附着模式与退出语义；不重写项目、不引入通用控制器/队列/事件框架。
- Shell/插件观察默认开启；安全边界、16 MiB 单文件和前后共享 64 MiB 内容预算保持。
- 历史空间先统计/预览/确认再清理，默认不自动过期；不自动清理用户实际数据。
- 预算维持 Agent 生命周期，明确重启边界；持久预算/精确 token 暂缓。
- 个人自用，当前 TUI 候选限定 macOS arm64；公开商店/签名公证和完整辅助技术专项不阻塞。
- 延续项目当前 main 工作方式，分批本地提交，不自动公开发布。

## 顺序与完成条件

1. **基线和记录**：冻结当前源码构建、启动及文件/体积清单；活动与历史分离，保留 SHA、范围和链接，不改 Git 历史。
2. **正确性**：任务图最小失败传播修复；compact/fork 中断故障注入，完成摘要/来源/Plan 继承后才发布子会话，失败保持保守边界。自动压缩事务保持。
3. **结构**：共用现有 Source/callback UI流程，保留本地会话保护与附着 epoch/权限/回执；删除无生产引用旧存储 API、保留旧数据读取；按行为合并重复测试，动态入口不可静态误删。
4. **工具/交互**：复用批量安全读取，小文件每批最多100、大于2 MB单读，预算跨前后共享，失败不完整；减少重复落盘、状态/回执复制和无变化重绘。生成中输入/滚动/取消、焦点和草稿正确；先测端到端再改调度。
5. **空间**：发布bundle node-pty并仅删除外平台prebuild，保留目标helper和fallback；map作为同SHA调试附件。空间统计/预览/确认清理重检运行及引用，保留文字/凭据/草稿/回执并说明清理影响。
6. **启动/内存/历史**：按新证据处理剩余耗时，不重复撤回实验；最终构建 30 分钟稳定性及一次内存快照。多会话回收、有界列表/按需详情与多端负载矩阵 2026-10-26 按自用范围砍除，有性能证据再开。
7. **补缺**：按provider能力、MCP生命周期、本地资源显式安装重载、Hikaro/Pi入口兼容、通用附件顺序，独立切片交付；不扩大到市场/自动监听/任意二进制请求。
8. **移动和候选**：定位高速输入、减少整页刷新；Android/真机输入/扫码/网络/锁屏/杀进程/通知；最终同SHA安装升级回退及一次实际账号闭环。双端竞争、耗电与全异常矩阵已砍。

## 接口与兼容

内部TUI去重不改命令行为；空间/MCP/资源沿现有配置/RPC增量扩展并能力协商，旧端明确不支持。Provider声明可选、旧配置可读；半成品会话不能运行。清理不能伪造空历史/成功回退。权限、租约、取消、持久回执与未知结果不重放保持。

## 验证

每切片有意义的红绿回归、定向检查；整合后全量类型/构建/测试。纯文档不新增测试。启动3次预热、30次测量，p95 200 ms 为参考值，以同条件对照基线不退化验收，输入≤16 ms；本地delta至PTY输出≤33 ms（不含模型/网络，可合并不丢字）。观察测100/1k/10k文件；最终完整30分钟窗口加一次内存快照。

包、安装、开发依赖、用户数据分开计量；性能优化超过同条件噪声才保留，结构简化不得性能回退。无新变更/失败不重复验收；修复后必须绑定新SHA。外部证据不可用时保留未验，不使用百分比。tutorial最后清单与哈希必须完全相同。
