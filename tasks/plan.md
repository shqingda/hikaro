4. 两端发布验收：真机网络/相机/锁屏/杀进程，多端竞争，发布性能、30 分钟稳定性、安装升级回退、版本/changelog 和正式渠道。真实外部凭据/设备不可用时保留待验项并继续其他可执行工作。

## 边界

- 手机不增加权限；host 在审批/执行时重新校验会话与 control 授权。未知结果不自动重发，重连只核对持久回执。
- 取消必须针对用户看到的运行；旧运行确认不能停止后继运行。收到取消回执不等于已停止，终态以 host 事件为准。
- 草稿按设备身份和任务隔离，离线/重启不自动发送；撤销清理本机身份和关联数据。
- 物理终端/真机结果由对应环境提供，自动化或模拟器不冒充人工 IME、相机、耗电或签名分发验收。
- 每轮运行受影响的定向测试与必要检查，通过后审查、提交、推送。全目标未完成时保持 goal active。
